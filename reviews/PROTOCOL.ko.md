# FSE 2027 독립 리뷰 프로토콜

최종 원고의 각 리뷰 반복은 다음 조건을 모두 만족해야 한다.

1. 이전 리뷰에 참여하지 않은 새 서브에이전트를 생성한다.
2. 서브에이전트에는 대화 이력을 전달하지 않는다(`fork_turns: none`).
3. 입력 문서는 `paper/main.pdf` 하나만 제공한다. 소스, 아티팩트, 이전 리뷰,
   목표 점수, 저자의 해석은 전달하지 않는다.
4. 요청에는 아래 문장을 그대로 포함한다.

   > FSE 2027(https://conf.researchr.org/track/fse-2027/fse-2027-papers)에 제출할 논문인데 평가해줘.

5. 한국어로 `Overall Merit` 점수, reviewer confidence, FSE 기준별 근거,
   치명적 결함, 강점, 약점, 채택 수준에 필요한 변경을 요청한다. 특정 점수나
   채택 판정을 유도하지 않는다.
6. 응답은 요약하거나 고쳐 쓰지 않고
   `fse2027-independent-YYYY-MM-DD-NN.ko.md`에 원문 그대로 저장한다.
7. 한 리뷰어에게 수정본을 재평가시키지 않는다. 수정 후에는 다시 새 리뷰어를
   생성한다.

리뷰 프롬프트에는 이전 판정이나 “Accept가 필요하다”는 목표를 포함하지 않는다.
이를 통해 각 판정은 최신 PDF만을 근거로 한 독립 표본으로 유지한다.
