## 논문 요약

이 논문은 학생의 실제 제출 궤적에서 세 가지 감독 관계를 자동 추출한다. Progress는 테스트별 비퇴행 개선, Strict는 판정 등급의 엄격한 개선, Answer는 실패 상태에서 최종 정답으로의 직접 전이를 학습한다. 각 관계에서 세 개의 QLoRA 체크포인트를 훈련하고, 검증 실행으로 총 9개 중 3개를 선택한다. 실행 컨트롤러는 원래 프로그램을 fallback으로 포함하여 관측 테스트에서의 비퇴행과 선택적 AST TED 예산 준수를 보장한다.

가장 중요한 실험적 결론은 애초 직관과 다소 다르다. 전체 궤적을 직렬화하는 것 자체는 안정적인 이득을 보이지 않으며, 무제한 repair coverage 증가의 대부분은 관계 다양성이 아니라 독립 체크포인트의 seed 다양성에서 나온다. 혼합 관계 감독의 효과는 주로 작은 패치와 TED 예산 하의 repair coverage에서 관찰된다.

## 세부 평가

### Originality

중상 수준이다. 실제 제출 궤적을 execution-evidence order로 형식화하고, 관계별 감독과 seed 다양성을 `A1 → A3 → A9 → M9` 사다리로 분리한 설계는 신선하다. 특히 혼합 감독의 효과를 단순 ensemble 효과와 구별하려는 시도는 관련 LLM APR 연구보다 훨씬 엄밀하다.

반면 개별 구성요소인 QLoRA repair, 실행 기반 후보 선택, 다중 체크포인트, AST edit budget은 각각 기존 개념에 가깝다. 핵심 독창성은 새로운 repair 알고리즘 하나보다 이들을 결합하고 기제별 효과를 식별하는 실험 설계에 있다. “ZPD”는 측정된 교육학적 구성개념이 아니라 동기 부여에 머물며, 궤적 history 자체의 효과도 null이므로 ZPD 기반 repair라는 강한 해석은 지지되지 않는다.

### Importance of Contribution

교육용 APR에서 정답률과 학생 코드 보존을 구분하고, 큰 정답 프로그램으로의 대체보다 edit-constrained deployment frontier를 평가해야 한다는 문제 제기는 중요하다. 또한 긍정적인 결과만 강조하지 않고 checkpoint diversity가 실제 주효한 원인임을 밝힌 점은 커뮤니티에 유용한 부정적·기제적 결과다.

다만 실제 교육적 유용성, 이해 가능성, 학습 효과 또는 학생의 다음 행동은 측정하지 않았다. 따라서 중요성은 “실행 기반 교육용 APR 방법 및 평가”에는 높지만 “ZPD 또는 학습 지원”에 대한 기여로는 제한된다.

### Soundness

전반적으로 강하다.

- 동일 generation budget과 base model을 사용하는 Answer-3Seed 및 selection-matched Answer-9Choose3가 마련되어 있다.
- 문제 단위 clustered bootstrap, equal-problem estimand, paired comparison, Holm correction을 사용한다.
- hidden-test partition, problem-disjoint selection audit, user strata, seed 반복, Java student-held-out replication을 포함한다.
- null 및 역전 결과를 숨기지 않고 결론의 범위를 좁힌다.
- fallback을 포함한 observed-test non-regression과 TED budget 준수는 정의상 성립한다.

주요 우려는 다음과 같다.

첫째, 461개 portfolio-selection 문제 중 323개가 Seen test 문제 정체성과 겹친다. 저자들이 disjoint selector audit를 제공한 것은 좋지만, 이 설정에서는 `M9-A9`의 무제한 순위가 역전된다. 따라서 완전한 problem-disjoint selection을 sensitivity가 아니라 주 분석으로 삼는 편이 타당하다.

둘째, Unseen은 무작위 또는 난이도 층화 표본이 아니라 eligible trajectory 수가 적은 하위 10% 문제다. 이 분할은 명확히 설명되어 있지만 “일반적인 새 문제로의 일반화”를 대표하지 않으며, 높은 절대 Unseen RR도 해석하기 어렵다.

셋째, hidden tests는 원래 하나의 authored suite를 hash로 나눈 것이다. 후보 선택과 평가를 분리한다는 점에서는 유효하지만, 독립적으로 작성된 추가 oracle이나 semantic correctness를 제공하지는 않는다.

넷째, training relation마다 데이터 수가 크게 다르며 Answer가 더 많은 예제를 받는다. 이는 저자들이 Answer에 유리한 통제라고 설명했지만, 관계 의미와 학습 데이터 양/분포를 완전히 분리하지는 못한다.

### Evaluation

평가 범위와 통계적 주의는 본 논문의 가장 큰 강점이다. 997 Seen, 250 Unseen, 181 student-held-out Java 사례, 여러 seed와 예산, source-retention 지표, matched controls를 다룬다. LSGen과의 비교에서도 무제한 coverage에서는 열세이고 constrained frontier에서는 우세하다는 결과를 정직하게 제시한다.

그러나 중요한 완성도 문제가 있다. Table 1과 기여 문장은 **1.5B scale replication, exercise-held-out Java replication, prompt control**을 수행한 기여로 제시하고, 구현 절에서는 1.5B 및 exercise-held-out 설정까지 설명하지만 Results에는 해당 결과가 없다. PDF만으로는 이 기여들을 검증할 수 없다. 이는 단순한 부가 설명 부족이 아니라 명시적으로 내세운 실험 기여와 보고 결과 사이의 불일치다.

또한 중심 효과인 `M9-A9`는 무제한 Seen에서 +1.71점으로 구간이 0을 포함하고, Unseen에서는 0이며, student-held-out Java에서도 +0.55점으로 불확실하다. 예산 평균 효과도 Seen에서 +1.22점으로 작고 disjoint selection 평균 구간은 0을 포함한다. 특정 TED operating point에서는 긍정적이지만, 이 결과의 실용적 중요성과 budget 선택 비용을 더 명확히 정량화할 필요가 있다.

비교 대상도 제한적이다. Zero-shot과 LSGen은 유용하지만, 최신 execution-aware 또는 iterative LLM repair 방법을 동일한 3-generation·동일 테스트 조건으로 구현한 비교가 없다. 관련 연구와의 문헌상 비교는 충분하나 empirical state-of-the-art comparison은 다소 약하다.

### Presentation

문장은 정확하고 도표도 읽기 좋으며, Figure 1은 시스템 구성을 효과적으로 설명한다. 용어, 수식, 실험 대조가 일관적이고 부정적 결과의 범위도 세심하게 기술한다.

다만 초록이 지나치게 많은 수치와 구간을 압축해 핵심 메시지를 파악하기 어렵다. 6개의 RQ, 다수의 portfolio 변형과 TED 분석이 한정된 공간에 밀집되어 있어 독자가 primary claim과 robustness audit를 구분하기 어렵다. Table 1의 prospective/post-hoc 구분은 좋은 시도지만 “externally preregistered되지 않았다”는 사실과 각 분석이 정확히 언제 고정되었는지를 재현 가능하게 설명할 필요가 있다.

### Related-work Comparison

교육용 reference-based repair, neural repair, execution-aware repair, feedback/ZPD, knowledge tracing, ensemble을 폭넓게 다루며 자신의 위치를 비교적 정확히 제한한다. 특히 ZPD를 실제 학습 결과로 주장하지 않고 observational reachability와 구분한 점은 적절하다.

보강할 부분은 다음과 같다.

- CREF, SelfAPR, counterexample-guided repair, PyDex 등과 ZPDPatch의 입력 정보·반복 방식·generation budget·동일 문제 자료 접근 권한을 표 형태로 직접 비교할 필요가 있다.
- 다중 모델 APR와 CoCoNuT류 ensemble에 비해 “실행된 프로그램의 set-union 선택”이 무엇을 새롭게 제공하는지 더 선명하게 정리해야 한다.
- LSGen만 최신 경쟁 기준으로 택한 이유와 다른 실행 기반 LLM APR을 재현하지 않은 이유가 필요하다.

## 강점

- seed 다양성, pool selection, 관계 다양성, history serialization을 분리한 탁월한 mechanism-identification 설계
- null result와 순위 역전을 포함한 정직하고 신중한 결론
- 문제 단위 의존성을 고려한 통계 추론
- 동일 budget의 강한 Answer-9Choose3 대조군
- observed-test 비퇴행과 edit-budget 준수를 명시적으로 보장하는 controller
- 무제한 correctness와 patch locality를 혼동하지 않는 평가
- problem-held-out 및 student-held-out 외부 평가
- 높은 재현성 의식과 명확한 Data Availability 진술
- 전반적으로 완성도 높은 문장과 도표

## 약점

- history conditioning의 인과적 효과가 없으며 ZPD 관련 교육학적 결과도 측정하지 않음
- mixed relation target의 핵심 coverage 효과가 작고 여러 설정에서 불확실하거나 역전됨
- main Seen portfolio selection과 test의 문제 정체성 중복
- 1.5B, exercise-held-out Java, prompt-control 결과가 주장·방법에는 있으나 Results에는 없음
- Unseen 분할이 저자원 문제에 편향되어 일반적 문제 일반화를 대표하지 않음
- hidden tests가 독립 suite가 아니라 기존 suite의 분할
- Qwen 한 모델 계열에 집중되어 architecture-level 일반화가 불명확함
- 최신 execution-aware LLM APR과의 동일 조건 실험 비교가 부족함
- 절대 TED budget의 실용적 선택 근거와 작은 평균 효과의 실질적 의미가 충분히 입증되지 않음

## 치명적 결함 여부

**즉시 기각을 요구하는 치명적 soundness 결함은 발견하지 못했다.** 결과와 결론은 대체로 서로 일치하고, 저자들도 한계를 명시한다.

하지만 누락된 replication 및 prompt-control 결과는 현재 제출본을 그대로 Accept하기 어렵게 만드는 중대한 보고 완성도 문제다. 또한 selection/test 문제 중복 때문에 mixed-target 효과에 대한 주 분석의 독립성이 충분하지 않다. 두 문제 모두 수정 가능하므로 Reject보다는 Major Revision이 적절하다.

## Accept 수준에 필요한 구체적 변경

필수 변경:

1. 1.5B scale, exercise-held-out Java, prompt control의 전체 결과와 불확실성 구간을 제시하거나, 해당 실험을 기여와 방법에서 제거해야 한다.
2. test 문제와 겹치지 않는 validation 문제만으로 portfolio를 선택한 결과를 primary analysis로 승격해야 한다. 가능하다면 nested problem-level selection 또는 반복된 disjoint split으로 선택 변동성을 보고해야 한다.
3. 제목·초록·기여를 실제 증거에 맞춰 checkpoint diversity와 edit-constrained target effect 중심으로 재구성해야 한다. History serialization 및 ZPD 효과가 입증된 것처럼 읽히지 않아야 한다.
4. primary endpoint, primary portfolio, predeclared 분석과 post-hoc 분석을 더 명확히 구분하고, 다수 budget/selector 분석에 따른 선택적 해석 위험을 설명해야 한다.
5. 최소 하나의 최신 execution-aware/iterative LLM repair 방법을 동일 base model, 테스트, 최대 3회 generation 조건으로 비교하거나, 실행 불가능한 구체적 이유와 기능 단위 비교를 제공해야 한다.

강하게 권장하는 변경:

6. 독립적으로 작성된 추가 테스트 또는 더 강한 correctness oracle로 hidden-test 결론을 보강한다.
7. 다른 모델 계열에서 `A3-A1` 및 `M9-A9` 기제 결론을 재현한다.
8. 오류 유형, 현재 pass rate, 문제별 trajectory 수, 프로그램 크기에 따른 효과 이질성을 보고한다.
9. 초록의 수치 나열을 줄이고 “diversity가 unrestricted coverage를, relation target이 constrained locality를 설명한다”는 핵심 결론을 전면에 둔다.

## 최종 판단

**Major Revision**

이 논문은 평균적인 borderline 논문보다 실험 설계와 자기비판이 훨씬 강하다. 특히 저자들이 원래의 trajectory/ZPD 직관보다 checkpoint diversity가 실제 주효한 기제임을 밝혀낸 결과 자체는 FSE 독자에게 가치가 있다. 그러나 현재 버전은 일부 핵심 재현 실험을 수행했다고 주장하면서 결과를 제시하지 않고, primary Seen selection이 test 문제 정체성과 상당히 중복된다. 이 두 문제를 해결하고 기여를 실제 증거 범위에 맞게 재정렬한다면 Accept 수준에 도달할 가능성이 높다.
