## 독립 심사

**Overall Merit: 4 — Accept**  
**Reviewer Confidence: 4/5**

### 논문 요약

본 논문은 프로그래밍 과제의 제출 궤적에서 Progress, Strict, Answer 관계를 자동 추출하고, 관계별로 독립 학습한 QLoRA 체크포인트를 실행 결과에 따라 순차적으로 적용하는 ZPDPatch를 제안한다. 특히 \(A_1 \rightarrow A_3 \rightarrow A_9 \rightarrow M_9\) 비교를 통해 반복 호출, 학습 시드 다양성, 검증 기반 선택, 궤적 기반 타깃 다양성의 효과를 분리하려 한다.

가장 중요한 결과는 다소 역설적이지만 명확하다. 무제약 repair coverage 향상의 주된 원인은 궤적 정보 자체가 아니라 독립 체크포인트 다양성이다. 과거 제출을 프롬프트에 직렬화하는 것도 안정적인 이득을 주지 않는다. 반면 관계별 타깃은 편집 예산이 제한된 조건과 일부 exercise-held-out Java 조건에서 작지만 재현되는 효과를 보인다.

### 세부 평가

- **Novelty: 4/5.** 제출 궤적을 실행 증거에 기반한 중첩 관계로 형식화하고, 궤적 타깃과 체크포인트 다양성을 통제된 사다리 실험으로 분리한 점이 새롭다. 개별 구성요소인 QLoRA, 실행 기반 선택, ensemble coverage 최적화는 기존적이지만, 이들을 인과적 메커니즘 분리에 맞춰 설계한 방식은 독창적이다.

- **Technical Originality: 3/5.** Progress/Strict/Answer 관계와 비퇴행 실행 컨트롤러는 깔끔하지만, 유한 후보군의 exhaustive portfolio selection과 Hoeffding 기반 bound 자체는 기술적으로 깊은 새 알고리즘이라고 보기는 어렵다. 기여의 핵심은 알고리즘적 혁신보다는 문제 정식화와 실험적 식별 설계에 있다.

- **Soundness: 4/5.** 비교 예산, 모델, 프롬프트, 선택 기회 등을 세심하게 맞추고, 문제 단위 bootstrap, McNemar 검정, 교차 적합 선택, hidden-test 확인을 제공한다. 주장을 지지하지 않는 결과도 명시적으로 보고한다. 다만 주된 mixed-target 효과가 작고 분석 일부가 post-review/repository-frozen이므로 확증성과 탐색성의 경계가 완전히 해소되지는 않는다.

- **Empirical Evidence: 4/5.** 7B/1.5B, Python/Java, Seen/problem-held-out/student-held-out/exercise-held-out, 편집 예산, 프롬프트 및 verdict-order 통제까지 범위가 넓다. 반면 핵심 mixed-target 무제약 효과는 7B Seen에서 신뢰구간이 0을 포함하고, 1.5B에서는 음수이며, Unseen에서도 0이다. 유의한 Java exercise-held-out 결과 역시 네 개 exercise cluster에 기반한다.

- **Significance: 4/5.** “궤적을 넣으면 좋아질 것”이라는 직관을 부정하고 실제 이득을 체크포인트 다양성과 제한된 편집 조건으로 분해한 결과는 교육용 APR 및 LLM ensemble 연구에 유용하다. 다만 ZPDPatch 고유의 관계 타깃이 주는 절대 효과는 제한적이어서, 새로운 범용 repair 기술이라기보다 정교한 메커니즘 연구로 보는 편이 적절하다.

- **Clarity: 4/5.** 논문의 구성, 수식, 표, 그림은 전반적으로 명확하고 결과 해석도 신중하다. 그러나 21페이지에 많은 통제·추가 분석이 밀집되어 핵심 메시지가 흐려지고, “trajectory supervision”과 “trajectory conditioning”이 구분되지 않으면 독자가 방법의 실질적 성공 범위를 오해할 수 있다.

- **Reproducibility: 4/5.** 데이터 구성 규칙, 하이퍼파라미터, 시드, 실행 환경, 선택 규칙과 통계 절차를 상당히 상세히 기술한다. 하지만 재현 패키지가 “acceptance 후 공개”로 되어 있어 심사 시점에 실제 산출물과 구현을 독립적으로 검증할 수 없다. 대규모 생성 결과 및 캐시 의존성 때문에 코드와 체크포인트뿐 아니라 원시 후보·실행 기록의 공개도 중요하다.

### 강점

1. 핵심 메커니즘을 분리하는 \(A_1\), \(A_3\), \(A_9\), \(M_9\) 사다리가 매우 설득력 있다.
2. 부정적 결과를 숨기지 않는다. 특히 과거 제출 직렬화가 안정적인 이득을 주지 않으며 제거 시 오히려 성능이 향상된다는 사실을 명확히 보고한다.
3. 문제 의존성을 고려한 cluster bootstrap과 problem-balanced estimand를 제공한다.
4. portfolio 선택과 최종 테스트의 중첩 문제를 인식하고 five-fold problem cross-fitting으로 보완한다.
5. observed-test 비퇴행과 편집 예산 준수를 컨트롤러 수준에서 보장한다.
6. hidden-test 확인, 모델 크기 변경, Java 외부 데이터, 두 종류의 holdout을 포함한 검증 범위가 넓다.
7. LSGen보다 무제약 성능은 낮다는 불리한 결과와 TED가 교육적 품질의 직접 증거가 아니라는 한계를 정직하게 기술한다.
8. Figure 1과 주요 표의 렌더링 및 가독성은 양호하다.

### 치명적 약점 및 주요 우려

즉시 Reject를 요구할 단일 치명적 결함은 발견하지 못했다. 다만 다음 우려들은 최종 주장의 범위를 제한한다.

1. **논문의 대표 개념보다 checkpoint diversity가 실질적 승자이다.** 무제약 조건에서 \(M_9-A_9\)의 주효과는 작고 0을 포함하며, 1.5B와 Unseen에서도 재현되지 않는다. 과거 궤적을 직접 입력하는 것도 이득이 없다. 따라서 독자가 제목과 서론에서 기대할 “trajectory-conditioned repair의 우월성”은 실험으로 지지되지 않는다.

2. **편집 제약 효과의 크기와 안정성이 제한적이다.** 교차 적합된 여섯 예산 평균 효과는 +1.2점으로 신뢰구간 하한이 +0.10에 불과하다. 개별 예산과 Unseen 결과 다수는 0을 포함한다. 이는 흥미롭지만 강한 일반적 우월성으로 표현하기에는 취약하다.

3. **비교 대상의 범위가 제한적이다.** 강한 비교는 Zero-shot, Answer ensemble, LSGen에 집중된다. 최근 execution-aware 또는 교육용 neural APR 시스템들이 직접 비교되지 않아, 전체 분야의 최신 수준과 비교한 상대적 위치는 불명확하다.

4. **Unseen split이 무작위 문제 일반화가 아니다.** 문제별 궤적 수로 정렬해 하위 10%를 Unseen으로 삼았기 때문에 Seen과 Unseen의 분포 차이가 체계적이다. 따라서 “problem generalization”은 새로운 저자 정의의 저자원 문제 분포에 대한 결과로 한정해야 한다.

5. **분석 경로의 복잡성.** 많은 강건성 분석이 최초 결과 이후 repository-frozen 상태로 추가되었다. 투명하게 공개한 점은 긍정적이지만, 매우 많은 분석 중 강조된 양의 결과가 선택적으로 보일 위험은 남는다.

6. **구조 보존의 의미가 제한적이다.** TED와 토큰/라인 보존은 locality를 측정하지만, 가독성, 학습 효과, 학생 이해 가능성 또는 수정의 개념적 적절성을 보장하지 않는다. 논문도 이를 인정하나 시스템의 교육적 동기는 이 측정 간극보다 강하게 제시된다.

### 필수 수정사항

1. 제목, 초록, 서론에서 궤적 기반 방법의 성공 범위를 더욱 명확히 제한해야 한다. 특히 “submission history를 이용한 repair”와 “submission trajectory에서 offline supervision target을 채굴한 repair”를 분명히 구분해야 한다.

2. 가장 안정적인 결론이 checkpoint diversity 효과이고, mixed-target 효과는 편집 제약 및 특정 모집단에 국한된다는 점을 주된 기여로 전면 배치해야 한다.

3. 모든 \(M_9-A_9\) 결과에 대해 효과 크기, 신뢰구간, 선택 단위, cluster 단위를 일관된 표로 제시하고 confirmatory, sensitivity, exploratory 분석을 시각적으로 명확히 분리해야 한다.

4. Unseen split의 저자원 편향을 더 직접적으로 정량화해야 한다. Seen과 Unseen의 문제 난이도, 테스트 수, 코드 길이, 궤적 길이 및 사용자 분포 비교가 필요하다.

5. Java exercise-held-out 결과는 exercise cluster가 네 개뿐이라는 점을 본문 결과표 바로 옆에 표시하고, 해당 신뢰구간의 불안정성을 강조해야 한다.

6. LSGen 구현 변경과 원 논문 설정 간 차이, 그리고 다른 최신 APR 방법을 실행하지 못한 이유를 더 구체적으로 설명해야 한다.

7. 심사 또는 artifact evaluation 시점에 split manifest, 후보 생성 결과, 실행 캐시, checkpoint hash, selection 기록, 분석 스크립트를 제공해야 한다. “채택 후 공개”만으로는 핵심 실험을 검증하기 어렵다.

8. finite-family bound의 i.i.d. problem 가정이 실제 validation problem 구성과 얼마나 부합하는지 설명하고, 이론적 보장이 실험 결론에서 담당하는 역할을 축소하거나 명확히 해야 한다.

### 최종 판정 근거

이 논문의 가장 큰 장점은 애초의 직관을 방어하려 하기보다 정교한 통제를 통해 무엇이 실제로 작동하는지 분해했다는 점이다. 결과적으로 강하게 지지되는 것은 제출 이력을 프롬프트에 넣는 접근도, 혼합 궤적 타깃의 일반적 coverage 향상도 아니다. 독립 체크포인트 다양성이 무제약 repair의 주된 원인이며, 궤적 기반 타깃은 제한된 편집 예산과 일부 외부 모집단에서만 추가 가치를 보인다.

이 때문에 방법 자체의 범용적 우월성과 기술적 혁신성에는 한계가 있다. 그럼에도 실험 설계의 엄밀성, 부정적 결과를 포함한 투명한 보고, 다양한 복제와 교차 적합, 그리고 APR ensemble 연구에 주는 실질적 교훈은 FSE에 충분히 가치 있다고 판단한다. 주장 범위를 현재 증거에 맞게 유지하고 artifact를 제공한다는 조건에서 **Accept**를 부여한다.
