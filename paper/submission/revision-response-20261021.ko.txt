범위
이번 작업은 원고 수정과 보존 결과의 검산이다. 새 실험, 학습, 추론,
testcase 실행, 서버 작업, 모델 승격, 공개 업로드 또는 main push는 하지 않았다.
이전 독립 리뷰 원문과 부정적 결과는 그대로 보존했다. 이 기록은 새로운
독립 심사나 Overall Merit 판정이 아니다.

주요 수정
1. 통계: 기본 구간을 95% percentile problem-cluster bootstrap,
   10,000회로 명시했다. instance/equal-problem 가중, Java의 student/exercise
   cluster, 네 개 Strict/Progress × Seen/Unseen Holm family를 구별했다.
   McNemar의 독립 pair 가정을 명시하고 군집 구간의 대용으로 쓰지 않았다.
2. 분모: peer-match는 train 5,231/21,416, valid 306/2,685이다.
   Unseen Mixed/Zero-shot의 전체 공동 성공 142와 defined-TED 122를 구분했다.
   matched-target의 299/154와 defined-TED 278/134는 다른 비교다.
3. 측정값: TED의 성공·파싱 가능 조건, SequenceMatcher retention,
   percentage-point 단위, stable/unknown 정의, (regression+unknown)/n
   상한을 명시했다. 통계적 신뢰상한으로 잘못 읽히지 않게 했다.
4. 조건: matched Python/Java의 current-only 입력, 3개 seed 순서,
   greedy decoding, 동일 controller, batch/accumulation 및 checkpoint 선택을
   명시했다. frozen-history-selected triple과 current-only reselection을 분리했다.
   Java matched train/valid 600/118을 추가했다.
5. 실행 환경: 코드를 대조하니 Python subprocess와 Java container의 제한이
   달랐다. Python 2.5초/test·2048MB, Java 15초 compile + 15초 whole harness·
   shared 16GB로 고쳤다. Python minor version이 보존 manifest에 고정되지
   않았다는 한계도 표시했다. 현재 서버 버전을 과거 실험 버전으로 대신 쓰지 않았다.
6. 문헌: LSGen도 시간순 제출 pair와 0–3 iteration 비교를 사용한다는 점을
   원 출판본으로 확인했다. 부정확하게 읽힐 수 있는 3/5 missing-control
   주장을 제거하고, 원래 eight-study coding와 정정 기록을 함께 보존했다.
   연구의 차이는 progress-target 및 matched-source/fixed-candidate 통제로 명시했다.
7. 서지: CodeNet vol.1035, TIKTOC 235–250을 수정했다. LSGen, PyFiXV,
   Feedback-Ladders는 정식 출판 정보로 갱신했고 주요 방법명 대소문자를 보호했다.
   상세 출처 URL은 literature-breadth-correction-20261021.txt에 기록했다.
8. 사례: '341 compact joint repairs'의 median 예시를 연결할 보존 record가
   로컬에 없었다. 다른 largest-gap record로 대체해 출처를 꾸미지 않고 해당
   설명을 원고에서 제외했다. 실험값·원본 사례 파일은 삭제하지 않았다.
9. 형식: algorithm2e 독립 caption을 IEEE figure + algorithmicx로 교체했다.
   사용자 정의 newcommand, 글꼴/여백 축소 없이 본문 10쪽+참고문헌 2쪽이다.
   12쪽 전부 렌더링해 읽었고, 표·그림이 첫 언급 전에 보이도록 배치했다.
10. 재현성: code-free paired outcomes, metric code, aggregate evidence,
    condition manifest와 hashes를 익명 로컬 ZIP으로 준비했다. standalone
    verifier는 GPU·네트워크·학생 코드 실행 없이 결과를 검산한다.
