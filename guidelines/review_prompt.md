논문 최종 검토용 Agent에게는 단순 오탈자 교정보다, “게재 전 마지막 심사자”처럼 검토하게 하는 것이 좋습니다.

다음 항목을 검토하도록 지시하세요.

1. 연구 목적과 논리 구조
- 연구 문제/가설이 명확한가
- 서론에서 제기한 문제와 결론이 일관되게 연결되는가
- 각 장과 절이 자연스럽게 이어지는가
- 불필요한 반복이나 논리적 비약이 없는가
- 주장에 필요한 근거가 충분한가

2. 관련 연구 / 문헌 검토
- 중요한 선행연구가 누락되지 않았는가
- 단순 나열이 아니라 연구 간 차이와 한계를 분석하고 있는가
- 본 연구와 기존 연구의 차별점이 명확한가
- 인용한 논문의 내용과 실제 주장이 일치하는가
- 최신 연구가 적절히 포함되어 있는가

3. 연구 방법
- 데이터 수집 방법이 명확한가
- 데이터셋 규모와 구성 설명이 정확한가
- 모델/알고리즘 구조가 충분히 설명되어 있는가
- 비교 방법과 평가 방법이 타당한가

4. 실험 설계
- baseline 선정이 공정한가
- 비교 조건이 동일한가
- 여러 실험에서 데이터 분할이나 조건이 일관적인가
- 통계적 검증이 필요한 경우 포함되어 있는가

5. 결과
- 표와 그림의 숫자가 본문 설명과 일치하는가
- 같은 결과가 서로 다른 위치에서 다르게 작성되지 않았는가
- percentage와 percentage point를 혼동하지 않았는가
- 평균, 표준편차, 단위 등이 정확한가
- 최고 성능 표시가 실제 값과 일치하는가
- 결과를 과장해서 해석하지 않았는가
- 결과만으로 주장할 수 없는 인과관계를 주장하지 않았는가

6. 표(Table)
- 모든 표가 본문에서 언급되는가
- 열/행 이름과 단위가 명확한가
- bold/underline 표시가 정확한가
- 표의 수치와 본문에서 언급한 수치가 동일한가

7. 그림(Figure)
- 모든 그림이 본문에서 언급되는가
- 해상도와 글자 크기가 충분한가
- 축 이름과 단위가 존재하는가
- 색상에 의존하지 않고도 구분 가능한가

8. 수식
- 모든 기호가 처음 등장할 때 정의되는가
- 동일한 변수가 서로 다른 의미로 사용되지 않는가
- notation이 논문 전체에서 일관적인가
- 수식 번호와 본문의 참조가 일치하는가
- 수식의 차원이나 계산이 올바른가

9. 결론
- 연구 목적에 직접 답하고 있는가
- 새로운 결과를 갑자기 추가하지 않았는가
- 핵심 기여를 명확하게 요약하는가
- 결과를 과장해서 표현하지 않는가

10. 인용 및 참고문헌
- 본문의 모든 인용이 reference에 존재하는가
- reference의 모든 논문이 본문에서 인용되는가
- 저자명과 연도가 정확한가
- 논문 제목, 저널명, 학회명 등이 정확한가
- DOI 등의 정보가 정확한가
- 동일 논문이 중복 등록되어 있지 않은가
- 학회/저널의 citation style을 따르는가

11. 주장-인용 검증
- 해당 citation이 바로 앞의 주장을 실제로 뒷받침하는가
- 원 논문이 주장한 범위보다 과장하여 인용하지 않았는가
- secondary citation이 아닌 원 논문을 인용할 수 있는가
- 여러 논문을 함께 인용했을 때 모든 논문이 해당 주장과 관련 있는가

12. 용어 및 표기 일관성
예:
- dataset / data set
- pre-trained / pretrained
- real-time / realtime
- Fig. / Figure
- Table / Tab.
- accuracy / Accuracy

같은 개념을 논문 전체에서 동일한 용어로 사용하는지 검토하게 하세요.

13. 약어
- 처음 등장할 때 full name이 있는가
- 한 번만 사용되는 약어가 불필요하게 정의되어 있지 않은가
- 동일한 약어가 다른 의미로 사용되지 않는가
- Abstract와 본문에서 각각 다시 정의해야 하는지 저널 규정과 맞는가

14. 문법 및 Academic Writing
- 문법 오류
- 어색한 영어 표현
- 지나치게 긴 문장
- 모호한 대명사
- 불필요한 수동태
- 구어체 표현
- 같은 표현의 반복
- 과도한 강조 표현

특히 다음 표현을 찾아보게 하면 좋습니다.

“obviously”
“clearly”
“significantly” → 통계적 의미인지 확인
“prove”
“always”
“never”
“best”

근거 없이 강한 표현을 사용하고 있는지 확인합니다.

15. 숫자 전체 Cross-check
Agent에게 논문의 모든 숫자를 추출해서 서로 비교하게 하는 것도 효과적입니다.

예:
- Abstract 성능
- Results 성능
- Table 성능
- Conclusion 성능

동일한 실험 결과가 여러 곳에서 동일하게 작성되어 있는지 확인합니다.
