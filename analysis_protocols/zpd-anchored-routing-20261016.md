## Intervention and mechanism

History-conditioned generation sometimes repairs cases the current-only route
misses, but also loses many previously correct repairs. Test whether retaining
one current-only candidate prevents its wholesale displacement while allowing
history to contribute a complementary candidate. This changes candidate routing,
not the public selector, model, training, prompts or evaluation gate. It does NOT
assume that public selection guarantees private-test correctness.

Every arm has exactly two terminal slots plus the unchanged original source:

| Arm | Slot 0 (shared anchor) | Slot 1 (controlled secondary route) |
|---|---|---|
| C | C-trained adapter, C prompt, original draw 0 | H-trained adapter, C prompt, original draw 1 |
| H | same anchor | H-trained adapter, H prompt, original draw 1 |
| HS | same anchor | H-trained adapter, HS prompt, original draw 1 |
| U | same anchor | H-trained adapter, U prompt, original draw 1 |

Thus C also receives two independently trained adapters; adapter diversity and
candidate budget cannot alone explain an H-over-C gain. C/HS/U keep the same
current anchor, second-draw index and trained H adapter. Prompt-specific frozen
seeds remain as originally declared; they are not replaced with new seeds.

Use only these fixed slots from the two authenticated completed runs. Draw 0
comes from original C; secondary C draw 1 comes from crossed C; secondary
H/HS/U draw 1 comes from the original paired run. Slot numbers are chosen without
per-candidate correctness inspection. No pooling of all draws, seed swapping,
retry-fill, failure removal, old private-label reuse, or additional generation
is permitted. The resulting 2,560 arm-slot references contain 1,600 unique
origin attempts (a shared anchor is referenced four times). Failures and exact
duplicate code remain in the ledger. This is replay-based method development,
not a new independent generation replication or a confirmatory experiment.
An outcome-blind real-artifact assembly check found nine retained overflow
slots (three each in H/HS/U): only one history slot per arm is now used. No
overflow was discarded or retried. The exact plan and routed-row hashes are
fixed in source before selection; no private labels or public scores entered
that check.
