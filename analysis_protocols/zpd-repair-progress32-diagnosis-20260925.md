## 5. Candidate availability, compressed representation and margin obstruction

272 banks contain at least one known stable-AC candidate. Another13 have unknown
candidates but no known AC, giving the possible-oracle bound285;35 banks have
no known or possible AC under the recorded labels. H selects205 known AC and
misses67 banks with a known AC. Candidate generation failure cannot explain
those67 misses, although it limits the35 definitely unsuccessful banks.

Group each bank's candidates by their **complete exact H32 vector**. Within a
class, `B(c)+theta·phi(c)` always preserves the frozen base order and SHA tie
rule, for **every theta**. Only each class's base champion can ever be selected.
The number of banks with a known-AC class champion is258, versus oracle272.
Consequently14 known-AC misses are blocked by feature-class collision under
this fixed base:12 banks have all-zero H vectors, including6 with no eligible
opportunity;2 have nonzero vectors but the relevant AC shares a class with a
higher-base non-AC. This ceiling is necessary, not proof that one shared linear
theta can jointly realize all258 choices.

Separately, for the frozen base winner b and each known-AC candidate c, compute

`slack(c) = B(b)−B(c)−||theta_H||₂ ||phi(c)−phi(b)||₂`.

In63 of the67 misses every AC candidate has slack>1e-12; the smallest positive
bank slack is0.00077772979. No coefficient vector within the **currently learned
fold-specific norm radius** can move any AC above even the original base
winner. This is not impossibility at every radius and is **not** evidence that
increasing C/norm would improve repair. The14 class obstructions are included
in these63, not additional misses. A disjoint partition is:

- 14 feature-class blocked;
- 49 class-accessible but current-radius blocked;
- 4 class-accessible and not excluded by that radius bound.

Fold radius-blocked counts are3,13,14,8,25. They include all6 missed known-AC
originals and57 known-nonAC misses. For the best-H-score known-AC alternative
in each of the67 misses, the residual contribution favors the wrong chosen
candidate in9, favors that AC alternative in7, and is zero within1e-12 in51.
Thus weak leverage and wrong-direction changes coexist; it is not solely a
too-small-coefficient story.

The14 collisions establish a limitation of this compressed representation with
a fixed base, **not** that new semantic information is necessarily required.
The underlying current/candidate features may already distinguish those
programs—the base gives them different scores—but those features cannot be
reweighted by this additive residual. Retaining/relearning raw current features
could break this restriction without new labels or a semantic execution channel.
No such method is fitted or assumed successful in this diagnosis.

## 7. One recommended next methodological step

Prepare a **jointly trained raw-current candidate ranker with authentic
history-progress interactions**, with an explicit same-current/input-access
matched control and the full existing history controls. The reason is the
combination of high known-AC oracle272,14 compressed-feature class obstructions,
63 current-radius obstructions, and only6 changed base choices—not a favorable
control's aggregate score. A joint model can learn current-feature weights
together with history rather than inherit an immutable base ordering. Preserve
the all320 bank/cohort and unknowns if this remains a development experiment;
freeze feature capacity, objective, comparison and endpoints before any fit.

This is a new testable hypothesis, not a guarantee that history contains useful
predictive information. Genuine matched-current superiority is still required;
H failing CF/Jm/HS remains the present conclusion. Do not increase residual C,
amplify the residual, select the four radius-accessible cases, route using known
current correctness, promote CF, or regenerate candidates to rescue these gates.
No proposed next fit is authorized by this diagnosis. Evidence of learning,
causal ZPD benefit or unseen private-test generalization remains absent.
