현재 pairwise 선택기는 risk filter 없이 모든 후보 및 no-op의 점수 최댓값을
선택한다. 28개는 non-AC의 점수가 최고 AC보다 높았고, 1개는 점수가 정확히 같아
SHA tie-break에서 non-AC를 선택했다. 즉 추가 생성만으로 해결할 문제가 아니다.

그 1개 `p02658:s974402292`는 명확한 표현 한계다. 선택 non-AC
`88ab6792...`와 AC `dd2b48d6...`의 compact 특징 및 lexical feature dictionary가
모두 동일하다. 유일한 핵심 차이는 다음 순서다.

```python
# non-AC: 곱하기 전 상한을 검사
if ans > 10**18:
    ans = -1
    break
ans *= A[i]

# AC: 곱한 결과의 상한을 검사
ans *= A[i]
if ans > 10**18:
    ans = -1
    break
```

토큰 bag에는 순서가 없으므로 해당 쌍은 같은 모델군 안에서 계수만 재학습해도
구분할 수 없다. 다만 이 한 사례로 나머지 28개도 모두 같은 원인이라고 단정할 수 없다.

## H의 약세: 규제 선택과 이력 특징을 분리해야 한다

새 128에서 C/H 선택이 56개 다르다. H만 AC는 11개, C만 AC는 13개이며,
H만 퇴행은 12개, C만 퇴행은 11개다. C 84 / H 82만으로 이력 자체가 해롭다고
단정할 수 없다.

원래 32 valid에서 C는 lexical regularization C=.1, H는 C=1로 선택되어 H의
규제가 10배 약하다. lexical 계수 L2는 C 2.727 / H 14.274다. 같은 C=.1인
원래 valid C/H/U는 모두 22 AC인데 H C=1의 24 AC가 선택을 결정했다.
학습의 독립 단위는 58 사용자/prefix이며, 1,900개 pair 행은 950쌍의 mirrored
표현이지 1,900개 독립 사례가 아니다. 소표본 선택 변동/과적합은 가능성이지 확정 원인이다.

이번 C만 AC인 13개에서 H 점수의 `H가 고른 non-AC − C가 고른 AC` 차이를
정확히 분해하면 lexical 항은 12개에서 잘못된 선택을 선호했고 평균 +0.369313이다.
반면 이력 항의 합은 4개에서만 잘못된 선택을 선호했고 평균 −0.026671이다.
전체 평균 score 차이는 +0.248198이다. 이전 absolute-gain 모델의 reverse-overlap
오류 진단을 그대로 복사하여 이번 H 오류도 전부 이력 특징 때문이라고 설명하면 안 된다.

표현 한계는 여전히 있다. H는 C의 lexical 코드 표현에 소수의 이력 overlap 값을
추가하며, 학생의 오류 개념/이전 성공·실패 유형을 직접 모델링하지 않는다.
또한 고정 current/candidate/test의 실행 정답은 이력에 따라 바뀌지 않으므로,
현재 loss만으로 학생별 교육적 적절성이 학습됐다고 주장할 수 없다.

## 사실에 근거한 다음 수정 후보

가장 직접적인 단기 병목은 AC 순위 개선에 동반되는 퇴행이다. **정확성 순위와
퇴행 위험을 별도 학습하고, 첫 attempt의 예측 위험을 기준으로 후보를 제한하는
독립 개발 family**는 위 교차표와 no-op 편향에 대응한다. 단, 예측 위험 제한은
실제 비퇴행 보장이 아니다. baseline/no-op 포함, unknown 제외 및 보존, user/prefix
가중, 새로운 자료에서 frozen 검증이 필요하다. 데이터 확대 시 mean-one weight를
그대로 쓰면 총 loss 증가로 정규화 효과가 달라지므로 비교 총가중량도 고정해야 한다.

토큰 순서를 구분하는 특징은 확인된 동률 충돌에 대한 후속 후보이나, 한 번에
여러 표현/목표를 바꾸면 어느 수정이 작동했는지 분리할 수 없다. 이번 보고서에서는
새 모델이나 threshold를 시험하지 않았으며 frozen 결과를 수정하지 않았다.
